PAMLA v1.0

Predictive Agriculture Machine Learning Assistant

Ask for a 24-hour soil moisture reading forecast. PAMLA uses your saved sensor history and a trained XGBoost model, then explains the result.

Each question is independent -- context window is 4,096 tokens. Forecasts start from the timestamp of the latest observation in the dataset -- not necessarily today, unless the data pipeline provides such immediacy. Watering recommendations and other forecast horizons are not supported.
